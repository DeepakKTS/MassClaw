01What MassClaw is

A NANDA-native federated operating layer for AI agents. A stock agent hands MassClaw a plain-English task. MassClaw decomposes it into a DAG, picks specialised agents for each node (trust × cost × latency), executes them in parallel while tracking a budget, critiques every output with a reflection engine, pauses for a human when policy says so, and produces a signed, auditable receipt for every decision — all replicated across a three-node federation via CRDT gossip.

  • NANDA-native
  • CRDT federation
  • Ed25519 signed memory
  • 10 policy rules
  • Reflection cache
  • HITL checkpoints
  • Cross-node resume
  • Signed audit
  • 616 backend tests

05Major systems

detail view

Policy engine

  • 10 rules auto-loaded on startup (priority 10 – 999)
  • Aggregate precedence: deny > escalate_human > allow > abstain
  • Registry live-toggleable: POST /policy/registry/rules/{id}/enable|disable
  • Dry-run: POST /policy/registry/evaluate
  • Every non-abstain → signed CRDT memory record

Reflection + HITL

  • Four-branch dispatch: accept / retry / re_plan / abort
  • Cache keyed on sha256(goal + outputs) · 10-min TTL
  • Retry → SelfCorrectionEngine rebuilds prompt
  • Re-plan → DynamicReplanner injects {id}_alt node
  • Abort → signed WorkflowCheckpoint

Cross-node resume

  • POST /workflows/{id}/resume {checkpoint_hash}
  • Validates approval status + workflow_id match (409 on mismatch)
  • WorkflowResumer is idempotent
  • Creates missing Workflow row on a peer that never had it
  • Re-enters scheduler via AgentSelector.select_agents_for_dag()

Shared memory / CRDT

  • Signed + content-addressed; duplicate hash → SAVEPOINT dedup
  • 256-bucket Merkle summary; pull-on-mismatch gossip
  • Checkpoints + approvals + decisions all on same path
  • Federation: docker/federation.yml · 12 containers
  • Lifecycle GC capped at 10 000 rows/tick

10Edge case catalog

50+ concrete probesdocs §19 →

Input / schema (10)

  • Empty prompt → 422
  • Invalid UUID → 422 with errors[].loc
  • Bad JSON → 422 · VALIDATION_ERROR
  • Body > 1 MiB → 413 · PAYLOAD_TOO_LARGE
  • Unknown route → 404 envelope
  • Wrong method → 405 envelope
  • Unicode round-trip → 200
  • Long request_id → 422 (128-char cap)
  • Bad ?action= in audit → 422

Policy engine (7)

  • Disabled rule stops firing; another takes over
  • Two denies → first wins, both in contributing_rule_ids
  • Crashing rule → abstain; others still run
  • Non-Decision return → abstain
  • Priority tie-break deterministic
  • Empty registry evaluation → abstain
  • Dry-run with rule_ids=[x] bypasses other rules

Memory / CRDT (5)

  • Duplicate checkpoint → SAVEPOINT dedup
  • Racing writer → existing row wins
  • Hash ≠ canonical body → SignatureMismatchError
  • Unsigned memory write → policy deny
  • Parent-hash cycle → rejected

HITL / resume (7)

  • Unknown checkpoint hash → 404 envelope
  • Mismatched workflow_id → 409
  • Denied approval + resume → 409
  • Double-resume → idempotent
  • Double-approve same id → 409
  • Expired approval (TTL) → status=expired
  • Peer without Workflow row → creates shadow

Reflection / retry (4)

  • Same output hash twice → cache hit
  • Retry at MAX_RETRIES → refuses
  • Re-plan on no-parent node → injects {id}_alt
  • Abort failing to save → logged, still marks failed

Federation (4)

  • Partition mid-write → survives writer, gossips after heal
  • Kill mid-write → peers with prior pull retain record
  • Gossip target 404 → logged; next tick tries another peer
  • Merkle bucket mismatch → pulls just that bucket

Identity (4)

  • Corrupt instance key → KeyStoreError at startup
  • Rotate key → AgentFacts re-publish (DID changes)
  • did:web with no HTTP → caller pre-verifies
  • Signature ↔ pubkey mismatch → rejected

Frontend (4)

  • API timeout > 30 s → ApiError("TIMEOUT") toast
  • next_steps from envelope → in toast text
  • Refetch during unmount → canceled via React Query
  • Theme toggle → no visible flicker (CSS vars)
