Major systems

Policy engine

  • 10 rules auto-loaded at startup (priority 10 – 999)
  • aggregate() precedence: deny > escalate_human > allow > abstain — 12 tests
  • Registry live-toggleable via POST /policy/registry/rules/{id}/enable|disable
  • Dry-run endpoint /policy/registry/evaluate usable from the UI tester
  • Every non-abstain decision → signed CRDT memory record (via record_decision)

Reflection + HITL

  • Four-branch dispatch: accept / retry_task / re_plan / abort — 6 integration tests
  • Reflection cache keyed on sha256(goal + outputs) — 10 unit tests
  • Retry delegates to SelfCorrectionEngine, re_plan to DynamicReplanner
  • Abort persists a signed WorkflowCheckpoint via CheckpointStore
  • Approval gate saves checkpoint BEFORE blocking; hash attached to ApprovalRequest

Cross-node resume

  • POST /workflows/{id}/resume {checkpoint_hash, approval_id?}
  • Validates approval status + checkpoint ↔ workflow_id match → 409 on mismatch
  • WorkflowResumer is idempotent — double-resume converges to the same rows
  • Creates missing Workflow row when the originator is dead (federation case)
  • Background scheduler re-enter via AgentSelector.select_agents_for_dag

Shared memory / CRDT

  • Signed + content-addressed; duplicate hash → SAVEPOINT-protected dedup (fixed Day 18)
  • 256-bucket Merkle summary + pull-on-mismatch gossip every 5–30 s
  • Checkpoints, approvals, and policy decisions all ride the same path
  • Federation compose ready (docker/federation.yml); live run conditional on Docker
  • Lifecycle GC batch-capped (10 000 per tick) to prevent worker OOM
